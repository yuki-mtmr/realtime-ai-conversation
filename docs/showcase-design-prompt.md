5 パターンを別セッション（または別 worktree）で 1 本ずつ作る。「デザインの方向性」だけ差し替える。

```
# 目的
自社の技術力を示すショーケースの LP を 1 ページ作る。
見る人: <想定顧客>。見終わった時の感想: 「<例: この会社なら任せられる>」

# デザインの方向性（このパターン固有）
<下の表から 1 つ>
参照: <URL or スクショ 2〜3 枚>。真似るのは <余白 / 書体 / モーション> だけ

# 制約
- リポジトリ内の既存サンプル（samples/ 等）は一切読まない・参照しない
- 流用してよいのは <ビルド設定 / GSAP 初期化 / ディレクトリ構成> のみ
- 技術: <Next.js / GSAP / Lenis 等>

# 進め方（各段階で止まって私の確認を待つ）
1. コンセプトを 3 行で書き、デザイントークン（書体 2 種・配色 5 色・余白スケール）を定義
2. セクション構成をワイヤー（テキスト）で提示
3. 実装。セクションを 1 つ作るたびにスクショを撮り、参照と比べて自己修正
4. 最後に 375px / 1440px で確認

# 完成条件
- 最初の 1 画面で方向性が伝わる
- モーションは <スクロール連動 / ホバー> を中心に、1 セクション 1 演出まで
```

## 5 パターンの方向性

| # | 方向性 | 主役 |
|---|---|---|
| 1 | エディトリアル（雑誌風・大きな明朝／セリフ体・余白多め） | 書体 |
| 2 | ミニマル・Apple 型（製品のクローズアップ＋スクロール連動） | モーション |
| 3 | ブルータリズム（グリッド露出・高コントラスト・等幅フォント） | 構造 |
| 4 | 3D／WebGL 主体（Three.js のヒーロー） | 没入感 |
| 5 | データ可視化型（数字・実績をアニメーションで見せる） | 実証 |

## 運用メモ

- 形容詞（「モダンで洗練された」等）は収束の原因。主役を 1 つに決めて伝える
- 手順 1〜2 で必ず止めて確認する（方向のずれを最小コストで直せる）
- モデル: Opus 5.5 / effort medium から開始。不足点を言語化できたら high
