## 技術メモ
- GSAP: スクロール連動・タイムライン演出の標準
- Three.js / React Three Fiber: 3D・WebGL（方向性 4）
- Manim: Python で数式・図解アニメを **MP4 動画として書き出す**ツール（Web 上でリアルタイムには動かない）。
  使うなら「事前レンダリング動画を埋め込む」形。Web ネイティブの代替は Motion Canvas（https://www.motioncanvas.io）/ Theatre.js（https://www.theatrejs.com）
