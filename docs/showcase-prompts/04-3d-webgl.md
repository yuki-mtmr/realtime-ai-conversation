# パターン 4: 3D / WebGL

下のコードブロックをそのまま新しい Claude セッション（Opus 5.5）に貼る。

```
# 目的
自社の技術力を示すショーケースの LP を 1 ページ作る。
見る人: 旅行業の役員（技術者ではない。数秒で「すごい」と「任せられる」を感じてほしい）。
見終わった時の感想: 「この会社なら、うちの旅行体験を次の水準に上げられる」
コピー・画像は仮で良い（後で差し替える前提。画像はプレースホルダかフリー素材）。

# デザインの方向性（このパターン固有）
3D / WebGL 主体の没入型 LP。主役は没入感。
- スクロールに合わせてカメラが 3D 空間を進み、旅の行程（出発 → 移動 → 目的地）を体験させる
- 抽象的・ハイテクな質感（光、パーティクル、ガラス、フォグ）。写実ではなく「未来的」
- テキストは最小限。3D の前に重ねる
参照: https://www.igloo.inc/ （スクロールで 3D 世界を進む構成）/ https://lusion.co/ （WebGL の質感）
真似るのは カメラワークと質感 だけ

# 制約
- リポジトリ内の既存サンプルは一切読まない・参照しない
- 流用してよいのは ビルド設定・ディレクトリ構成 のみ
- 技術: Next.js + TypeScript + React Three Fiber + drei + postprocessing + GSAP ScrollTrigger
- モバイルでは描画負荷を下げる（DPR 上限 1.5、パーティクル数を削減）
- WebGL 非対応時は静止画にフォールバック

# 進め方（各段階で止まって私の確認を待つ）
1. コンセプトを 3 行で書き、デザイントークン（書体 2 種・配色 5 色・余白スケール）を定義
2. セクション構成をワイヤー（テキスト）で提示
3. 実装。セクションを 1 つ作るたびにスクショを撮り、参照と比べて自己修正
4. 最後に 375px / 1440px で確認。prefers-reduced-motion 時は演出を控えめにする

# 完成条件
- 最初の 1 画面で方向性が伝わる
- 1 セクション 1 演出まで。演出同士を競合させない
- 60fps を目安に、重い処理はスクロール外で止める
```
