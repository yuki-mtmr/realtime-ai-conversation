# パターン 3: プロダクト SaaS 型

下のコードブロックをそのまま新しい Claude セッション（Opus 5.5）に貼る。

```
# 目的
自社の技術力を示すショーケースの LP を 1 ページ作る。
見る人: 旅行業の役員（技術者ではない。数秒で「すごい」と「任せられる」を感じてほしい）。
見終わった時の感想: 「この会社なら、うちの旅行体験を次の水準に上げられる」
コピー・画像は仮で良い（後で差し替える前提。画像はプレースホルダかフリー素材）。

# デザインの方向性（このパターン固有）
Linear / Stripe 型のプロダクト LP。主役は「アプリが動いている様子」の UI 演出。
- 旅行予約・AI 旅程作成・運用ダッシュボードの画面を、実際に操作されているようにアニメーションで見せる
  （カーソルが動き、入力され、結果が生成される）
- 暗めの背景に光のグラデーション、精密な細い線、控えめなグロー
- 技術力（ケイパビリティ）を機能ごとのカードで見せ、各カードに小さな動きを付ける
参照: https://linear.app （アプリが動く様子のアニメーション）/ https://stripe.com/jp （ケイパビリティを見せる動き）
真似るのは UI デモの見せ方・光と線の質感 だけ

# 制約
- リポジトリ内の既存サンプルは一切読まない・参照しない
- 流用してよいのは ビルド設定・ディレクトリ構成 のみ
- 技術: Next.js + TypeScript + Tailwind + Framer Motion
- アニメ部品は Originkit（https://www.originkit.dev/）から必要なものだけ選んで使ってよい
- UI デモは画像ではなく実際の HTML/CSS で組む（動画にしない）

# 進め方（各段階で止まって私の確認を待つ）
1. コンセプトを 3 行で書き、デザイントークン（書体 2 種・配色 5 色・余白スケール）を定義
2. セクション構成をワイヤー（テキスト）で提示
3. 実装。セクションを 1 つ作るたびにスクショを撮り、参照と比べて自己修正
4. 最後に 375px / 1440px で確認。prefers-reduced-motion 時は演出を控えめにする

# 完成条件
- 最初の 1 画面で方向性が伝わる
- 1 セクション 1 演出まで。演出同士を競合させない
- 60fps を目安に、重い処理はスクロール外で止める
```
